How to Run

Everything you need to run Erratanomicon Legacy.

What is Erratanomicon?

The Erratanomicon Loric allows the Demon to edit character abilities throughout the game.

The Demon may change one word per night. The Demon cannot add or remove words. The Demon may make changes to the same character more than once. The Demon can make a number of changes up to the number of Minions in the player count.

In a 12-player game, the Demon may make up to 2 changes during the game, each on separate nights.

Any changes are up to Storyteller discretion. Keep the game fair and fun!

Each night, before anything else, the Demon may choose to edit a character ability. If they do, the character ability is edited on the character sheet, and any players who have that character token learn that their ability has been edited and what the edit was.

If the Demon chooses to edit, whether the edit is successful or not, they do not wake to kill that night. The Demon still wakes for any other abilities, such as learning bluffs and Minions, learning they were chosen by the Exorcist or Nightwatchman, or choosing a Lleech host.

In this Legacy version, any changes made are kept for future games.

What is Legacy?

If a player is executed, their character is added to the graveyard. That character is permanently removed from the script and replaced with another character.

How to Run

1

Start the Game

Click Copy JSON or Download JSON and import the file into botc.app.

2

Edit Abilities

While playing, mark down any changes the Demon makes by clicking on a word and changing it. These changes are permanent.

3

Mark Executed Characters

If a player is executed, tap the elimination button to mark that character as eliminated. Before the next game, that character will be added to the graveyard and replaced.

4

Good Team Errata

At the end of the game, one good player is selected randomly. That player publicly makes one change to an evil character ability, following the same rules as the Demon: they may change one word, but may not add or remove words. This change is also permanent.

5

Finalize the Game

Press Update Changes. You will see the ability edits made during the game and which eliminated characters are being replaced.

If you do not like a replacement character, press Skip & Eliminate Character to move that character to the graveyard and generate another replacement. The skipped character is permanently eliminated and will not appear as a future replacement.

6

Save the Legacy

Press Copy JSON or Download JSON inside the Update Changes modal to save the updated legacy for the next game.

Happy Errataing!
