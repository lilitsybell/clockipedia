ERRATANOMICON LEGACY

How to Run

Everything you need to run Erratanomicon Legacy.

What is Erratanomicon?

The Erratanomicon Loric allows the Demon to edit character abilities throughout the game.

The Demon may change one word per night. The Demon cannot add or remove words. The Demon may make changes to the same character more than once. The Demon can make a number of changes up to the amount of Minions in the player count. In a 12-player game, the Demon may make up to 2 changes in the game, each on separate nights. Any changes are up to Storyteller discretion. Keep the game fair and fun!

Each night, before anything else, the Demon may choose to edit a character ability. If they do, the character ability is edited on the character sheet and any players who have that character token learn their ability has been edited and what the edit was.

If the Demon chooses to edit, whether they were successful or not, they do not wake to kill that night. The Demon still wakes for any other abilities, such as learning bluffs and Minions, learning they were chosen by the Exorcist or Nightwatchman, or choosing a Lleech host.

In this Legacy version, any changes made will be kept for future games.

What is Legacy?

Any players that are executed are added to a graveyard. Those characters are removed from the script permanently and replaced.

How to Run

To start, simply click Copy JSON or Download JSON and import the file into botc.app.

While playing, mark down any changes the Demon has made by clicking on a word and changing it. These changes are permanent.

If a player is executed, tap the eliminated button to mark that character as eliminated. Before the next game, that character will be added to the graveyard.

At the end of the game, press the Update Changes button. You will see any edits made and which characters are being replaced. If you do not like a replacement character, press the Skip & Eliminate Character button to move that character to the graveyard. It will not show up again in future replacements.

To save, press Copy JSON or Download JSON inside the Update Changes modal.

Happy Errataing!
